# Cities & Destinations Directory

This folder holds city-specific factual profiles, landmarks, local food recommendations, and notes for the 15 New Zealand destinations.

## Intended Structure
Each city will have a dedicated markdown reference file:
`cities/<city-slug>.md`

### Standard Content for City Files:
1. **Official & Māori Name** (e.g., Auckland / Tāmaki Makaurau, Wellington / Te Whanganui-a-Tara, Christchurch / Ōtautahi, Queenstown / Tāhuna)
2. **Island & Region** (North Island / South Island)
3. **Core Highlights & Anchors** (Specific lookouts, beaches, walking tracks, streets)
4. **Verified Local Food & Coffee Spots**
5. **Key Seasons & Travel Notes**
